# TUI 디자인

이후 TUI 화면은 이 문서의 컴포넌트 패턴을 따른다. 각 컴포넌트의 자리표시는 `Main Title`, `description`처럼 역할을 나타내는 이름으로 적는다.

## popup

화면을 가리는 모달이다. 열려 있는 동안 입력은 popup만 받고, 뒤 화면은 그리지 않는다.

화면 중앙에 둔다. 가로 52열 이상이고, 얇은 테두리만 있다. 배경색은 지정하지 않는다.

```text
┌──────────────────────────────────────────────────────┐
│                                                      │
│  Main Title                                          │
│                                                      │
│  description                                         │
│                                                      │
│                              action      action      │
│                                                      │
└──────────────────────────────────────────────────────┘
```

* `Main Title`은 왼쪽 위에 굵게 둔다.
* `description`은 제목 아래 왼쪽에 둔다. 추가 설명이나 오류가 있으면 그 아래에 이어 적는다.
* `action`은 오른쪽 아래에 가로로 나란히 둔다. 개수는 상황에 따른다.
* 선택된 `action`만 반전한다. 한 번에 하나다.

### 입력

키보드 모드로 시작한다. 처음 선택된 `action`은 왼쪽 첫 항목이다.

마우스가 움직이면 마우스 모드로 바뀐다. 키보드가 잡고 있던 반전은 사라진다. 커서가 어떤 `action` 위에 있으면 그 항목만 반전되고, `action` 밖이면 반전은 없다.

키보드 입력이 오면 키보드 모드로 돌아온다. 마우스 반전은 꺼지고, 키보드가 가리키는 `action`만 반전된다. 직전 마우스가 `action` 위에 있었다면 그 항목을 키보드 선택으로 이어받는다.

| 입력 | 동작 |
| --- | --- |
| 마우스 이동 | 마우스 모드. 커서 아래 `action`만 반전 |
| 왼쪽 클릭 | 커서 아래 `action`을 실행 |
| 왼쪽·오른쪽 화살표 | 키보드 모드. `action` 사이를 이동 |
| Enter | 키보드가 가리키는 `action`을 실행 |

## 사용 중인 popup

손상된 `.data/index.json`을 만나면 입력 상자보다 먼저 popup을 연다. 파일이 없으면 popup 없이 빈 인덱스로 시작한다.

| 자리 | 내용 |
| --- | --- |
| Main Title | `Failed to load index` |
| description | `Recreate the index?` |
| action | `reset index`, `quit` |

`reset index`는 `./documents`로 인덱스를 다시 만든다. 저장에 성공하면 popup을 닫고 입력 상자를 연다. 실패하면 손상된 파일을 유지하고 `description` 아래에 오류를 남긴다. `quit`은 프로그램을 종료한다.
