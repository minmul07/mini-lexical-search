# TUI 디자인

이후 TUI 화면은 이 문서의 컴포넌트 패턴을 따른다. 각 컴포넌트의 자리표시는 `Main Title`, `description`처럼 역할을 나타내는 이름으로 적는다.

TUI의 전체 화면 배경은 검정색으로 칠한다.

## popup

화면을 가리는 모달이다. 열려 있는 동안 입력은 popup만 받고, 뒤 화면은 그리지 않는다.

화면 중앙에 둔다. 가로 52열 이상이고, 얇은 테두리만 있다. 배경색은 전체 화면과 같은 검정색이다.

```text
┌──────────────────────────────────────────────────────┐
│                                                      │
│  Main Title                                          │
│                                                      │
│  description                                         │
│                                                      │
│                              action      action      │
│                                                      │
└──────────────────────────────────────────────────────┘
```

* `Main Title`은 왼쪽 위에 굵게 둔다.
* `description`은 제목 아래 왼쪽에 둔다. 추가 설명이나 오류가 있으면 그 아래에 이어 적는다.
* `action`은 오른쪽 아래에 가로로 나란히 둔다. 개수는 상황에 따른다.
* 선택된 `action`만 반전한다. 한 번에 하나다.

### 입력

키보드 모드로 시작한다. 처음 선택된 `action`은 왼쪽 첫 항목이다.

마우스가 움직이면 마우스 모드로 바뀐다. 키보드가 잡고 있던 반전은 사라진다. 커서가 어떤 `action` 위에 있으면 그 항목만 반전되고, `action` 밖이면 반전은 없다.

키보드 입력이 오면 키보드 모드로 돌아온다. 마우스 반전은 꺼지고, 키보드가 가리키는 `action`만 반전된다. 직전 마우스가 `action` 위에 있었다면 그 항목을 키보드 선택으로 이어받는다.

| 입력 | 동작 |
| --- | --- |
| 마우스 이동 | 마우스 모드. 커서 아래 `action`만 반전 |
| 왼쪽 클릭 | 커서 아래 `action`을 실행 |
| 왼쪽·오른쪽 화살표 | 키보드 모드. `action` 사이를 이동 |
| Enter | 키보드가 가리키는 `action`을 실행 |

## 사용 중인 popup

손상된 `.data/index.bin`을 만나면 입력 상자보다 먼저 popup을 연다. 파일이 없으면 popup 없이 빈 인덱스로 시작한다.

| 자리 | 내용 |
| --- | --- |
| Main Title | `Failed to load index` |
| description | `Recreate the index?` |
| action | `reset index`, `quit` |

`reset index`는 `./documents`로 인덱스를 다시 만든다. 저장에 성공하면 popup을 닫고 입력 상자를 연다. 실패하면 손상된 파일을 유지하고 `description` 아래에 오류를 남긴다. `quit`은 프로그램을 종료한다.

## 홈과 검색 화면

검색 전 홈은 검색창 위 2줄 간격을 두고 중앙 정렬한 큰 아스키 아트 `SEARCH` 제목을 표시한다. 제목이 들어갈 너비나 높이가 부족하면 한 줄 `SEARCH`로 줄이고, 그마저도 어려우면 생략한다. 중앙의 흰색 테두리 입력 상자(최대 본문 100열)와 상태 라벨을 표시한다. 검색어를 `/` 없이 입력하고 Enter로 검색한다. `/`로 시작하는 입력은 명령으로 처리하며 빈 입력은 무시한다.

### 홈 인덱싱 진행

`/index`는 검색 결과·명령 출력 화면으로 전환하지 않고 홈의 검색창 위치를 유지한다. 인덱싱은 별도 스레드에서 실행하며 검색창 내부가 진행률에 따라 왼쪽에서 오른쪽으로 연한 회색으로 채워진다. 검색창 아래에는 메타데이터·토큰화·저장 단계의 완료 수와 소요 시간을 표시한다. 로그가 추가되어도 검색창의 위치와 너비는 바뀌지 않는다. 완료하면 100%까지 채운 뒤 750ms 동안 서서히 사라진다.

인덱싱 중에는 검색창을 편집할 수 있지만 Enter로 검색·명령을 실행하지 않는다. `/exit`, `/quit`, Ctrl+C는 인덱싱이 끝난 뒤 종료한다. 실패하면 같은 위치에 오류를 남긴다. 손상된 스냅샷의 `reset index`도 같은 화면을 사용하며 실패하면 복구 팝업을 다시 연다.

검색 후에는 좌우 2열 여백을 제외한 전체 너비를 사용하고 좌측에 정렬한다. 검색창과 실행된 검색어·검색 시간은 상단에 고정한다. 검색창에는 마지막 검색어를 유지하며, 편집 중에도 아래의 실행된 검색어와 결과는 다음 Enter까지 유지한다. 입력 상자는 최대 3줄이며 초과 내용은 커서를 따라 내부 스크롤한다.

```text
╭────────────────────────────────────────────────╮
│ 자료구조 AND 검색                             │
╰────────────────────────────────────────────────╯
검색: 자료구조 AND 검색  (0.123 ms)
[하위경로/파일.txt] 10+
  12: …자료구조와 검색이 등장한 주변 원문
      화면 너비에 맞춰 이어지는 내용
  28: 다른 매칭 행
[더보기 · 15행 남음]
──────────────────────────────────────────────────
[다음파일.md] 2
   3: 일치하는 원문
   8: 일치하는 원문

[이전]  Page 1  [다음]
↑↓: 검색창/결과  Space/Enter: 실행  Esc: 홈  | Ready
```

결과 영역만 스크롤한다. 페이지 컨트롤과 상태·조작 안내는 하단에 고정한다. 첫·마지막 페이지의 사용할 수 없는 버튼은 흐리게 표시하며 선택하지 않는다. 좁은 화면에서는 페이지 버튼을 `<`·`>`와 페이지 번호로 줄인다. 파일 사이에는 전체 결과 너비의 수평선을 둔다.

### 결과 행과 강조

각 행은 원본 줄 번호와 본문을 표시하며 이어지는 줄은 본문 위치에 맞춘다. 원문이 3줄 이내이면 전부 표시한다. 넘으면 첫 키워드 일치 지점 앞에 본문 너비의 최대 ¼만큼 문맥을 두고 최대 3줄로 발췌한다. 생략한 앞뒤에는 `…`를 붙인다. 작은 화면에서는 결과 영역 높이만큼만 표시한다.

너비는 바이트 수가 아닌 FTXUI의 터미널 셀 기준이다. 한글·결합 문자·ZWJ 이모지·피부색 수식자·국기 쌍을 중간에서 자르지 않는다. 한 글자 자체가 영역보다 넓으면 대체 문자로 표시한다. 원문의 ASCII 제어 문자는 공백으로 바꿔 표시한다.

검색창의 이동·삭제·마우스 커서 배치와 화면 줄바꿈도 같은 글리프 경계를 사용한다. ZWJ 이모지·피부색 수식자·국기 쌍·이모지 표시 선택자(VS16)·키캡 조합은 한 글리프로 편집하고 2셀로 표시한다. 반복 입력하거나 리사이즈해도 원문과 논리 커서 위치를 유지한다.

표시된 검색 토큰 전체를 낮은 대비의 배경색으로 강조한다. 인덱싱과 동일하게 영문 대소문자를 정규화하고 단어 경계를 적용한다. 예를 들어 `alpha`는 `ALPHA`를 강조하지만 `alphabet`은 강조하지 않는다. 질의의 `AND`·`OR` 연산자는 강조 대상이 아니다. 선택 행은 첫 줄의 `>`와 밑줄로 구분하며 키워드 강조를 유지한다.

### 파일 페이지·더보기

파일 건수는 전체 중복 제거된 매칭 행 기준으로 1~10은 실제 숫자, 11 이상은 `10+`다. 더보기에는 아직 펼치지 않은 정확한 행 수를 표시하고, 모두 펼치면 버튼이 사라진다. 실패한 파일은 경고를 표시하고 더보기를 제공하지 않는다.

새 페이지는 파일을 하나 추가하기 전에 누적 매칭 행이 50 미만인지 확인한 뒤 해당 파일의 처음 최대 10행을 통째로 추가한다. 49행에서 다음 파일의 10행을 추가하면 59행이다. 제목·경고·더보기와 화면상 줄바꿈은 원본 매칭 행 수에 포함하지 않는다.

더보기는 다음 최대 10행을 추가하고 첫 추가 행을 선택한다. 새 표시 행은 200ms 동안 ease-out으로 순차 표시되며, 기존 스크롤 위치를 유지해 더보기 위쪽 내용이 움직이지 않는다. 첫 추가 행은 더보기 버튼이 있던 자리에 표시되고, 아래의 다른 항목들은 새 행이 자리를 차지하는 만큼 함께 밀려 내려간다. 애니메이션 중 키 입력·좌클릭·휠 입력이 오면 즉시 완료 상태로 전환한다. 50행 초과를 허용하며 기존 페이지 경계와 다른 파일 배치를 유지한다. 페이지 왕복 시 펼친 상태를 보존하고, 페이지 이동 후 결과 맨 위부터 표시한다. 첫/마지막 페이지에서는 해당 방향의 페이지 버튼을 비활성화한다. 더보기와 페이지 이동은 키보드·마우스로 버튼을 조작해서만 실행한다.

| 입력 | 동작 |
| --- | --- |
| ↑ / ↓ | 검색창에서는 줄 사이 커서 이동. 마지막 줄의 ↓로 첫 결과 진입. 결과에서는 매칭 행·더보기·페이지 버튼 순서로 이동하며 첫 항목의 ↑로 검색창 복귀 |
| Home / End | 결과의 첫/마지막 선택 항목으로 이동 |
| PgUp / PgDn | 현재 결과 영역 높이만큼 스크롤 |
| 결과 위 마우스 휠 | 표시 행 기준 3줄 스크롤 |
| 결과 행 더블클릭 / 선택 후 Space·Enter | 해당 파일 뷰어를 선택한 원본 줄에서 열기 |
| 버튼 클릭 / 선택 후 Space·Enter | 더보기 또는 파일 페이지 이동 |
| Esc | 결과·명령 출력에서 홈으로 복귀 |
| Ctrl+C, `/exit`, `/quit` | 프로그램 종료 |

검색창의 Space는 공백 입력, Enter는 검색·명령 실행으로 유지한다. 결과 영역에서는 Space 또는 Enter로 선택한 행의 뷰어를 열거나 버튼을 실행한다.

검색창으로 돌아오면 기존 입력과 커서 위치를 유지한다. 선택 가능한 결과나 버튼이 없으면 ↓는 검색창에 머문다. 홈과 일반 명령 출력에서도 입력 경계를 넘어 포커스를 이동하지 않는다. Tab·Shift+Tab은 포커스를 바꾸지 않는다.

키보드 선택 이동은 선택 항목을 화면에 표시한다. 휠·PgUp/PgDn은 선택을 바꾸거나 선택 위치로 화면을 되돌리지 않는다. 리사이즈 시 현재 터미널 너비·높이로 다시 배치하고 스크롤 범위를 보정한다.

버튼은 파일 경로를 직접 전달하므로 선행·후행 공백을 포함한 경로의 공백을 그대로 보존한다.

### 파일 뷰어

매칭 행을 더블클릭하거나 선택 후 Space·Enter로 해당 파일의 읽기 전용 뷰어를 연다. 한 번의 클릭은 행 선택만 한다. 검색창과 페이지 버튼은 숨기며, 상단 파일 상대 경로·본문·하단 단축키 안내를 표시한다. 검정 배경과 좌우 2열 여백을 유지한다. 검색 토큰 강조는 유지하고 진입한 원본 줄의 첫 표시 행에 `>`를 둔다. Markdown도 원문으로 표시한다.

진입 줄의 시작은 본문 최상단에서 5개 표시 행 아래에 두되 중앙보다 아래에 두지 않는다. 목표 위치는 0부터 세어 `min(5, (본문 높이 - 1) / 2)`이며 파일 시작에서는 위쪽 문맥이 있는 만큼만 표시한다. 파일 끝에서는 하단 빈 공간을 허용해 진입 줄이 중앙 아래로 밀리지 않게 한다. 리사이즈·줄번호·줄바꿈 전환 시 본문 위쪽의 원본 줄·글리프 위치를 기준으로 다시 배치한다.

| 입력 | 동작 |
| --- | --- |
| ↑ / ↓ | 표시 행 기준 1줄 스크롤 |
| PgUp / PgDn | 본문 높이만큼 스크롤 |
| Home / End | 파일 처음 / 끝 |
| 마우스 휠 | 세로 3줄 스크롤 |
| 본문 드래그 | 표시 행 기준 텍스트 선택. 줄번호와 `>` 마커는 선택·복사에서 제외 |
| 선택 후 우클릭 | 선택 텍스트를 OSC 52로 시스템 클립보드에 복사 |
| n | 원본 줄번호 전환. 기본 켜짐. 후속 표시 행의 번호 영역은 비움 |
| w | 자동 줄바꿈 전환. 기본 켜짐 |
| ← / → | 줄바꿈이 꺼진 경우 가로 1셀 스크롤 |
| Ctrl+휠 위 / 아래 | 줄바꿈이 꺼진 경우 왼쪽 / 오른쪽 3셀 스크롤 |
| Esc | 검색 결과로 복귀. 검색어·입력 커서·선택·스크롤·페이지·펼침 상태 보존 |
| Ctrl+C | 프로그램 종료 |

하단 안내는 고정하고 좁은 화면에서는 축약한다. 줄바꿈이 켜져 있으면 가로 이동을 무시하고, 줄바꿈을 켤 때 가로 위치를 초기화한다. 전체 줄바꿈에서도 검색 결과와 같은 셀·글리프 경계·제어 문자 표시 규칙을 사용한다. 가로 스크롤의 경계에서 잘리는 전각 글리프는 공백으로 표시한다.

선택은 현재 화면에 표시된 본문 범위로 제한하며 화면 밖 자동 스크롤은 하지 않는다. 줄바꿈된 표시 행 사이는 개행으로 복사한다. 선택은 스크롤·줄번호/줄바꿈 전환·리사이즈·뷰어 닫기에서 해제한다. 복사 결과는 `Copied to clipboard.`를 화면 우측 상단의 검정 배경 테두리 박스로 표시한다. 박스는 최종 위치에서 오른쪽으로 박스 폭과 여백만큼 벗어난 지점에서 ease-out 300ms로 슬라이드 인하고, 슬라이드인 완료 후 3초 유지한 뒤 오른쪽으로 ease-out 300ms로 슬라이드 아웃한다. 슬라이드 중 검정 배경은 화면에 실제로 보이는 팝업 영역에만 칠하고 나머지 화면은 그대로 노출한다. 우클릭 복사는 OSC 52를 사용하므로 지원하지 않는 터미널(VTE 계열 등)에서는 시스템 클립보드에 반영되지 않는다.

뷰어를 열 때마다 디스크 원문 전체를 다시 읽고 열린 동안 메모리에 보관한다. 매번 줄번호 켜짐·줄바꿈 켜짐으로 시작한다. 읽기 실패는 뷰어에 오류로 표시하고 Esc 복귀를 허용한다. 인덱싱 당시 줄이 사라졌으면 마지막 줄로 이동하고 `/index` 안내를 표시한다. 빈 파일도 오류 없이 복귀할 수 있다. 원문 읽기 성공·실패는 검색 세션을 변경하지 않는다.

### 홈 복귀·오류·명령 출력

Esc 홈 복귀는 입력·실행 검색어·결과·오류·선택·스크롤·페이지·펼침 상태를 지우고 입력 상자에 포커스를 둔다. 로드된 인덱스와 저장 파일은 유지한다. 홈에서 Esc는 입력을 유지하며 아무 동작도 하지 않는다. Esc는 어떤 화면에서도 종료하지 않으며 인덱스 복구 팝업에서는 무시한다. 팝업의 기존 `quit` 버튼은 유지한다.

검색 결과가 없으면 `No matches.`를 표시한다. 새 검색 실패 시 이전 결과를 제거하고 실행한 검색어와 오류를 표시한다. `/help` 등 일반 명령은 텍스트 출력 화면을 사용한다. `/index`는 홈 인덱싱 진행 화면을 사용한다. `/help`는 검색 세션을 유지한다.

새 검색 시도·인덱싱·재생성 시작과 Esc 홈 복귀는 이전 세션을 무효화한다. 읽기에 실패한 파일은 같은 세션에서 재시도하지 않는다.

`--no-tui`는 기존 `=============================` 구분선·파일 그룹 형식으로 모든 매칭 행을 출력하며 발췌·강조·더보기·페이지 상태·탐색을 제공하지 않는다.
