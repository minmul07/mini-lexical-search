# TUI 디자인

이후 TUI 화면은 이 문서의 컴포넌트 패턴을 따른다. 각 컴포넌트의 자리표시는 `Main Title`, `description`처럼 역할을 나타내는 이름으로 적는다.

## popup

화면을 가리는 모달이다. 열려 있는 동안 입력은 popup만 받고, 뒤 화면은 그리지 않는다.

화면 중앙에 둔다. 가로 52열 이상이고, 얇은 테두리만 있다. 배경색은 지정하지 않는다.

```text
┌──────────────────────────────────────────────────────┐
│                                                      │
│  Main Title                                          │
│                                                      │
│  description                                         │
│                                                      │
│                              action      action      │
│                                                      │
└──────────────────────────────────────────────────────┘
```

* `Main Title`은 왼쪽 위에 굵게 둔다.
* `description`은 제목 아래 왼쪽에 둔다. 추가 설명이나 오류가 있으면 그 아래에 이어 적는다.
* `action`은 오른쪽 아래에 가로로 나란히 둔다. 개수는 상황에 따른다.
* 선택된 `action`만 반전한다. 한 번에 하나다.

### 입력

키보드 모드로 시작한다. 처음 선택된 `action`은 왼쪽 첫 항목이다.

마우스가 움직이면 마우스 모드로 바뀐다. 키보드가 잡고 있던 반전은 사라진다. 커서가 어떤 `action` 위에 있으면 그 항목만 반전되고, `action` 밖이면 반전은 없다.

키보드 입력이 오면 키보드 모드로 돌아온다. 마우스 반전은 꺼지고, 키보드가 가리키는 `action`만 반전된다. 직전 마우스가 `action` 위에 있었다면 그 항목을 키보드 선택으로 이어받는다.

| 입력 | 동작 |
| --- | --- |
| 마우스 이동 | 마우스 모드. 커서 아래 `action`만 반전 |
| 왼쪽 클릭 | 커서 아래 `action`을 실행 |
| 왼쪽·오른쪽 화살표 | 키보드 모드. `action` 사이를 이동 |
| Enter | 키보드가 가리키는 `action`을 실행 |

## 사용 중인 popup

손상된 `.data/index.bin`을 만나면 입력 상자보다 먼저 popup을 연다. 파일이 없으면 popup 없이 빈 인덱스로 시작한다.

| 자리 | 내용 |
| --- | --- |
| Main Title | `Failed to load index` |
| description | `Recreate the index?` |
| action | `reset index`, `quit` |

`reset index`는 `./documents`로 인덱스를 다시 만든다. 저장에 성공하면 popup을 닫고 입력 상자를 연다. 실패하면 손상된 파일을 유지하고 `description` 아래에 오류를 남긴다. `quit`은 프로그램을 종료한다.

## 파일별 검색 결과

출력은 입력 상자 아래 같은 너비에 표시한다. PgUp/PgDn은 출력 영역만 스크롤하고, 새 명령의 출력은 맨 위부터 표시한다. 긴 원문은 너비에 맞게 줄바꿈하되 매칭 행 수에는 원본 한 행으로 센다.

```text
=============================
[하위경로/파일.txt] 10+
1: 일치하는 원문
4: 일치하는 원문
...
 > 15 more
[다음파일.md] 2
3: 일치하는 원문
8: 일치하는 원문
=============================
Page 1 | previous: no | next: yes
```

파일 건수는 전체 중복 제거된 매칭 행 기준으로 1~10은 실제 숫자, 11 이상은 `10+`다. ` > N more`는 아직 펼치지 않은 정확한 행 수이며 모두 펼치면 없어진다. 실패한 파일은 경고를 표시하고 more를 제공하지 않는다.

새 페이지는 파일을 하나 추가하기 전에 누적 매칭 행이 50 미만인지 확인한 뒤 해당 파일의 처음 최대 10행을 통째로 추가한다. 49행에서 다음 파일의 10행을 추가하면 59행이다. 제목·경고·more는 행 수에서 제외한다.

| 입력 | 동작 |
| --- | --- |
| `/more <상대 경로>` | 현재 페이지의 파일을 다음 최대 10행만큼 펼친다. 공백 경로는 따옴표 없이 입력 |
| `/next`, `/prev` | 아직 배치하지 않은 파일들의 다음 페이지 / 캐시된 이전 페이지 |
| PgUp, PgDn | 화면을 넘는 출력 스크롤 |

펼치기는 50행 초과를 허용하고 기존 페이지 경계와 다른 파일 배치를 유지한다. 페이지 왕복 시 펼친 상태를 보존한다. 첫/마지막 페이지에서 범위를 넘는 이동은 현재 페이지를 유지한다. 새 검색 시도·인덱싱·재생성 시작 시 이전 세션을 무효화한다. 읽기에 실패한 파일은 같은 세션에서 재시도하지 않는다.

`--no-tui`는 동일한 파일 그룹 형식으로 모든 매칭 행을 출력하며 more·페이지 상태·탐색을 제공하지 않는다.
