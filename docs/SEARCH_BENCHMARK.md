# 검색 성능 기록

2026-11-04, Ubuntu 24.04.5 LTS / WSL2 x86_64, GNU g++ 13.3.0, C++20, CMake Release 빌드. 로컬 파일시스템과 따뜻한 OS 파일 캐시에서 워밍업 1회 후 별도 프로세스로 7회 실행한 중앙값이다. 인덱싱은 측정 전에 수행했다. 실제 터미널 출력은 측정하지 않는다.

각 파일은 `{단어} alpha beta\n`을 반복한다. 흔한 검색어는 1,000파일 × 100행 모두 `hit`, 희귀 검색어는 같은 구성에서 첫 파일만 `hit`이고 나머지는 `noise`다. 작은 파일은 5,000파일 × 1행, 긴 파일은 1파일 × 100,000행 모두 `hit`다. 질의는 모두 `hit`다.

| 구성 | 첫 페이지 ms | 10행 펼치기 ms | 다음 페이지 ms | 전체 순회 ms | 전체 파일 / 행 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 흔한 검색어 | 2.923 | 0.003 | 0.010 | 6.227 | 1,000 / 100,000 |
| 희귀 검색어 | 0.038 | 0.003 | 해당 없음 | 0.030 | 1 / 100 |
| 다수 작은 파일 | 21.223 | 해당 없음 | 0.083 | 27.891 | 5,000 / 5,000 |
| 긴 단일 파일 | 0.169 | 0.003 | 해당 없음 | 1.474 | 1 / 100,000 |

| 구성 | 로드 후 최대 RSS KiB | 첫 페이지 후 최대 RSS KiB | 전체 순회 후 최대 RSS KiB |
| --- | ---: | ---: | ---: |
| 흔한 검색어 | 6,028 | 6,376 | 6,516 |
| 희귀 검색어 | 6,056 | 6,056 | 6,120 |
| 다수 작은 파일 | 7,544 | 9,252 | 9,380 |
| 긴 단일 파일 | 5,472 | 5,472 | 5,600 |

모든 측정에서 읽기 경고는 0건이고 전체 순회의 파일·행 수는 입력과 일치했다. 최대 RSS는 Linux `/proc/self/status`의 VmHWM이며 로더의 임시 버퍼와 할당기 보유 메모리를 포함한다. 시점별 값의 차이를 검색 전용 메모리 사용량으로 해석할 수 없다. 원문 행을 출력하지 않는 순회 측정이므로 no-TUI의 실제 터미널 출력은 더 오래 걸린다. 하드웨어·파일시스템·캐시 상태에 따라 달라지는 관찰값이며 성능 보장 기준은 아니다.

재현 방법과 CSV 필드 설명은 [테스트 가이드](TESTING.md#검색-성능-측정)를 참고한다.
